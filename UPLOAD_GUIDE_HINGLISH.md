# Android se GitHub Pages par upload — sabse simple tarika

Ye package `shaileshkumar7y-max/New-show-` ke liye hai. Live website ka `index.html` self-contained hai: CSS, game logic aur artwork usi ek file ke andar embedded hain.

1. ZIP download karke Android Files app mein **Extract** karo.
2. GitHub par `https://github.com/shaileshkumar7y-max/New-show-` kholo, `main` branch aur root folder select karo.
3. ZIP ke root se ye chaar files upload/replace karo: `index.html`, `manifest.json`, `sw.js`, `icon.svg`.
4. `assets` folder, `app.js` aur `styles.css` ko upload karna zaroori nahi hai. Source ZIP mein editing ke liye woh alag `source/` folder mein preserved hain.
5. Commit changes. GitHub Pages deploy hone ke baad site ko Incognito tab mein kholo. Zaroorat pade toh cache clear karke 2 baar reload karo.

**Note:** Names, points, history aur custom prompts isi device ke browser mein save hote hain. Data clear karne se pehle Profile se backup export karna. 18+ screen self-confirmation hai, verified age check nahi.
