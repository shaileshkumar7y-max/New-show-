# BIG BOSS KE RANDIYA — BLACKED Premium Innerwear

A mobile-first, local-first reality-show party game. This repository is the actual GitHub Pages source for the BLACKED show experience.

## Main experience
- Custom BLACKED show identity and campaign artwork in the house homepage.
- Adult 18+ self-attestation and consent-first house rules.
- 23 playable modes, including Spin Wheel, Truth Bomb, Dare or Double, Secret Crush, Chemistry Test, Eye Contact Battle, Model Walk, Pose Challenge, Compliment Battle, Mystery Box, Who Knows Whom, Confession Room, Couple Sync, Temptation Test, Secret Mission, Boss Says, Hot Seat, Winner's Choice, Final Temptation, BLACKED Fashion Show, Task Arena and Date Night Generator.
- Three comfort selections: Flirty, Naughty and Temptation. Prompts stay non-graphic and focus on conversation, style, confidence and mutual choice.
- House dashboard, contestant roster, local leaderboard, daily task, fashion zone, trophies and favourites.
- Local storage for players, scores, history, custom prompts and preferences; JSON backup import/export.
- Responsive desktop/mobile layout, PWA manifest and offline service-worker cache.

## Run locally
Serve this folder over HTTP (for example `python -m http.server 8080`) and open `http://localhost:8080`. No build step, backend, API key, analytics or account is required.

## Deploy to GitHub Pages
Commit the repository root to the branch/folder configured by Pages. Required files: `index.html`, `styles.css`, `app.js`, `manifest.json`, `icon.svg`, `sw.js`, and `assets/black-ed-campaign.webp`.

## Boundaries / limitations
- The 18+ screen is a self-attestation, not verified age assurance.
- Progress is stored on the current browser/device. There is no cross-device multiplayer, public leaderboard, remote profile, checkout, or central analytics in this local-only release.
- Every challenge can be skipped, paused or stopped. No nudity, recording, forced touch or intimate activity is required or described.
- The show is an original game experience and is not affiliated with any television franchise.
